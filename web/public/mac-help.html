APPLE MAC INSTALLATION HELP

Your camera toolkit.
Now on your Mac.

A native app for Apple Silicon and Intel, with the same camera installation, site management and diagnostic tools available on Windows and Linux.

One download for Apple Silicon and Intel

Both Mac packages contain the same universal SADPTools.app. You do not need to choose a processor type. The app targets macOS 12 or later; this is a test release, with real Mac camera, desktop and codec testing still needed.

Install from the DMG or ZIP

  1. Choose the Apple Mac DMG or ZIP. To check file integrity, compare its SHA-256 with the published checksums. In Terminal, run shasum -a 256 ~/Downloads/your-downloaded-file.dmg, substituting your actual filename (or ZIP).
  2. Open the DMG and drag SADPTools to Applications. Alternatively, extract the ZIP and move SADPTools.app to Applications.
  3. Eject the disk image if you used it, then launch SADPTools from Applications. You can keep it in the Dock for your next camera job.

If macOS cannot verify the developer

These Mac builds are not Developer ID signed or notarised by Apple. They use an ad-hoc signature, which does not verify the publisher. Gatekeeper can therefore prevent the first launch. A matching checksum confirms the download’s bytes, not its safety or publisher identity.

If you trust the app, first try opening it, then look in System Settings → Privacy & Security for Open Anyway, where offered. Older macOS versions use System Preferences → Security & Privacy. Follow Apple’s guidance for opening downloaded apps. Keep security protections enabled; if your organisation blocks the app or macOS reports malware or damage, stop and check with your administrator.

Allow access to your camera network

When macOS asks, allow SADPTools to access your local network. On versions with this control, review System Settings → Privacy & Security → Local Network. See Apple’s local network permission guide.

If discovery is empty, check the selected adapter, network permissions, firewall and VPN. Local SADP discovery stays on the local network; use Add by IP or the IPv4 scanner for reachable routed cameras. A working route and permitted camera services are still required.

Live View and saved credentials

Live View opens in its own window and starts playback while you continue working. Try an H.264 stream first on Mac; H.265/HEVC playback depends on your Mac and macOS version.

Mac and Linux saved credentials use an encrypted vault with a master passphrase. Mac Keychain auto-unlock is not currently available. Windows keeps its existing account-based credential protection. Use an encrypted site backup when moving saved credentials between platforms.

Updating your Mac app

Optional in-app update checks recognise Mac packages. Installation is manual: save your work, quit SADPTools and its Live View windows, download the current Mac package, replace the app in Applications, then reopen it. Settings and sites are stored outside the app bundle; keep an encrypted site backup before an upgrade. The Mac updater does not overwrite a running app.

Windows retains its installer update flow. On Linux, install the current package for your distribution or use the manual installer.
