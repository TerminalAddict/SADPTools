BEFORE YOU PLUG IN

A few useful answers.

Made for the practical work that happens on site.

Meet Paul Willard ↗
What does SADP stand for?

SADP means Search Active Devices Protocol. Compatible Hikvision cameras and recorders use it for local network discovery. SADPTools uses SADP alongside other supported discovery and camera-management tools.

Is SADPTools an official Hikvision tool?

No. SADPTools is an independent application created by Paul Willard. It supports compatible Hikvision equipment but is not affiliated with or endorsed by Hikvision.

Does SADPTools run on Windows, Linux and Apple Mac?

Yes. Windows 10/11 AMD64 has an installer and a standalone ZIP. Linux AMD64 has DEB, RPM and a manual tar.gz installer, with a desktop menu icon. Apple Mac has a universal DMG and ZIP for Apple Silicon and Intel, targeting macOS 12 or later. Mac builds are available for testing; real Mac hardware validation is still needed.

How do I install and update SADPTools on a Mac?

Copy SADPTools.app from the DMG or ZIP to Applications. These test builds are not Developer ID signed or notarised, so macOS may show a Gatekeeper warning. Update checks recognise Mac packages; quit the app before replacing it manually. Saved sites and settings stay outside the app bundle. Read Apple Mac installation help.

Which cameras does it work with?

SADP discovery, activation and network configuration target compatible Hikvision equipment. ONVIF and ISAPI tools depend on what each camera or recorder supports and what your account permits. Features vary by model and firmware; support is shown in the app.

Can I reach a camera on another subnet?

Yes, if your computer has a working route and the required camera services are reachable. Add a known camera IP or scan an explicitly selected network. Multicast SADP discovery itself normally stays within the local broadcast domain.

Is there a subscription or cloud account?

No. SADPTools is free to use, with no application account or telemetry. Your sites and credentials stay on your computer. Device operations and update checks use network connections when requested or enabled.

Why does Windows show a warning?

Current unsigned builds can appear as an unknown publisher. SmartScreen also considers a file’s reputation. Read the Windows installation guide before deciding whether to run a download. Read Windows installation help.

Is every diagnostic or configuration action supported?

No. Capability and permission checks are part of the workflow. Firmware uploads, automatic replacement configuration, privacy-mask editing and verified replay retrieval are not available in this release. Features still need testing against your specific equipment.
