Camera installation guides

Find the device, configure supported cameras and carry the installation to the next laptop. These guides explain the steps in SADPTools, what you need before starting and how to check the result.

SADPTools is independent software by Paul Willard. Hikvision compatibility depends on the device and firmware; it is not an official Hikvision product.

Choose the job you are doing

SADP discovery for Hikvision cameras

SADPTools is a free, independent desktop application for finding and commissioning compatible Hikvision cameras and recorders on Windows, Linux and Apple Mac.

CCTV camera discovery, on site or across a route

Choose the discovery method that matches the network. SADPTools combines local camera discovery, known-IP access and explicit IPv4 scans in one Windows, Linux and Mac application.

CCTV installer software for the whole site visit

SADPTools keeps camera discovery, supported configuration, Live View and handover information together. Carry the same practical CCTV tools on a Windows, Linux or Apple Mac laptop.

How to activate a Hikvision camera

For a compatible inactive Hikvision device, SADPTools can set the initial administrator password over the local network. Discover the device, confirm its identity, activate it once, then verify the result.

How to change a camera IP address or enable DHCP

SADPTools can update the network settings of a compatible activated Hikvision device found through local SADP discovery. You need its current administrator password and the correct network settings for the site.

How to find a camera on a different subnet

If your computer has a working route to a camera, SADPTools can check its IP directly even when the camera does not share your subnet. Local SADP multicast discovery is a separate connection path.

How to configure cameras on Linux or Apple Mac

SADPTools provides a native desktop interface on Linux and Apple Mac for camera discovery, supported Hikvision activation and network changes, Live View and saved sites. Windows uses the same workflows.

How to transfer a camera site and its saved passwords

Use Export site to create an encrypted .sadpsite file, then Import site on the destination laptop. The file carries the saved site and known credentials independently of each laptop’s local password protection.
