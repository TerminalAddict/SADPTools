This website

This site has no advertising, analytics trackers or account registration. Fonts, images, scripts and downloads are served from this domain. Your light or dark theme preference is saved in your browser’s local storage.

The web server receives normal request information, including IP address, requested path and user agent, and may retain access and error logs for operation and troubleshooting. Do not put credentials or customer information into a website URL.

The desktop application

On Windows, Linux and Apple Mac, SADPTools keeps site inventories and protected credentials on your computer. Saved credentials use Windows account protection or a master-passphrase vault on Linux and Mac. It does not require a cloud account or add telemetry. It connects to selected devices and services for operations you request or enable, including optional update checks. Exported files go where you choose.

The Windows display runtime is supplied by Microsoft and has its own update and privacy terms, included with the installer. Network cameras and services have their own behaviour and policies.

Downloads

The server retrieves and verifies published release files, then delivers them from sadptools.com. Downloading does not create an account or enrol you in a mailing list.
