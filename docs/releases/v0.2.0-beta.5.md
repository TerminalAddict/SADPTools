# SADPTools v0.2.0-beta.5

This is the recommended beta for **security-question password recovery** and
the **routed-camera connectivity fix** introduced in beta.4.

The release also fixes an existing discovery test that could expire after
30 ms on Windows CI before processing any fixture replies. It now finishes
after the expected replies, with a separate timeout for failures. Application
behaviour is unchanged from beta.4; published beta.4 files have not been replaced.

## Changes since beta.3

- **Password recovery → Security questions** reads the selected camera's
  firmware support and three configured question labels. An explicit submission
  encrypts the original answers and new admin password. Availability checks
  do not validate answers or change passwords.
- Recovery uses the computer's route to the camera, including gateways,
  secondary addresses and VPN adapters. **Matching IPv4 subnets are not
  required.** Explicit adapter overrides are respected. Actual HTTP responses
  determine support; connection failures identify the attempted connection.
- Equivalent CLI recovery commands and regression tests are included.
  Credentials are excluded from inventory, preferences and logs. Resets are
  submitted once; a missing reply leaves the outcome unconfirmed.

## Install or update

Download **[SADPTools-0.2.0-beta.5-Setup-windows-amd64.exe](https://github.com/TerminalAddict/SADPTools/releases/download/v0.2.0-beta.5/SADPTools-0.2.0-beta.5-Setup-windows-amd64.exe)**
for Windows 10/11 AMD64. The offline display runtime is included. Windows/Linux
CLI archives, a build manifest and SHA-256 checksums are also supplied.

On beta.2 or newer, enable **stable and beta** updates, then select **About →
Check for updates → Update now**. Confirm About shows `0.2.0-beta.5` after setup.
Beta.1 and development builds need a manual upgrade.

For a standalone `SADPTools-windows-amd64.exe`, setup installs into the registered
installation or `%LOCALAPPDATA%\Programs\SADPTools` by default. It does not
replace an arbitrary standalone copy. Launch **SADPTools** from the Start menu
after setup.

## Validation and limits

Release checks cover Go tests, vet and race checks, frontend tests/build,
packaging/release-tool tests, Windows cross-compilation, embedded versions and
installer integrity. Uploaded files are downloaded and verified before
publication. Linux desktop compilation also passed for the recovery feature.

Read-only physical-camera checks retrieved configured questions on V5.5.61
firmware and exercised not-configured/unsupported responses on other cameras.
The Linux GUI question workflow was inspected. Encrypted resets and routed
connections have synthetic test coverage. **Physical-camera password reset/login,
the reported routed Windows connection, and Windows installation/update runtime
behaviour still need testing.** No real passwords were changed during development
or release preparation. Firmware support varies.

The application and setup remain **unsigned** while the SignPath Foundation
application is pending; SmartScreen warnings may still appear. Runtime and
dependency pins are unchanged from beta.3/beta.4.

See the [security-question recovery guide](https://github.com/TerminalAddict/SADPTools/blob/v0.2.0-beta.5/docs/security-question-recovery.md)
and [update guide](https://github.com/TerminalAddict/SADPTools/blob/v0.2.0-beta.5/docs/updates.md).
