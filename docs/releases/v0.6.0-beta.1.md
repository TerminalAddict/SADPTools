# SADPTools v0.6.0-beta.1 — Advanced diagnostics and field service

Beta release for technician testing. Windows runtime and physical-camera/NVR validation remain outstanding.

Windows users can choose the [offline Setup](https://github.com/TerminalAddict/SADPTools/releases/download/v0.6.0-beta.1/SADPTools-0.6.0-beta.1-Setup-windows-amd64.exe), which includes the display runtime, or the [standalone desktop ZIP](https://github.com/TerminalAddict/SADPTools/releases/download/v0.6.0-beta.1/SADPTools-0.6.0-beta.1-standalone-windows-amd64.zip). Extract the standalone ZIP before running the app. Linux DEB, RPM and manual installers, plus Windows/Linux CLI archives, are also attached. Windows binaries remain unsigned.

Adds ten tools under **Commissioning → Diagnostics & service**: connection troubleshooting, recording/gap metadata, replacement planning, firmware compatibility, security inspection, image tuning, protocol exploration, ANPR commissioning, equipment QR labels and reviewed support bundles/optional traces. Existing Live View, saved sites, credentials, reports and release packaging remain in use. Read [the guide and compatibility matrix](https://github.com/TerminalAddict/SADPTools/blob/v0.6.0-beta.1/docs/v0.6-diagnostics.md) before hardware testing.

## Validation

- `make check`: Go tests, vet, race detector; frontend tests; Windows/Linux and release-packaging tests.
- `make frontend`: generated Wails v3 bindings and production frontend build.
- Desktop-tag Go tests, vet and race detector.
- Windows AMD64 desktop and offline WebView2 Setup build; Linux GUI, CLI, DEB, RPM and manual installer build.
- Synthetic tests cover recording pagination/ambiguous timestamps, imaging identity/bounds/uncertain writes, RTSP description/authentication, ANPR dedup/unknowns/retention, replacement expiry/identity/history/backup references, labels after IP changes, support consent/redaction/checksums/encryption, CLI errors/cancellation and trusted SSH envelopes.

Native Linux GTK4/WebKitGTK smoke testing used Xvfb, a separate DBus session and isolated XDG directories. It exercised the diagnostics page, successful synthetic HTTP connectivity, ONVIF service/user/device inspection (including password redaction), advertised imaging controls, QR label preview and support-bundle preview. Recording failure/trust states were displayed without a replay claim; precise recording searches were validated by synthetic protocol tests. Custom input choices survived completed jobs. No real inventory or camera writes were used. Release artifact hashes are recorded in the attached `SHA256SUMS` and `build-manifest.json`. Synthetic fixtures use isolated storage; no fixture is shipped as a real discovered device.

## Physical/Windows checks still required

No physical camera/NVR write or packet trace was performed during this implementation. Windows runtime testing is separate from successful cross-compilation and packaging.

1. Install Setup / launch standalone on Windows; check About reports 0.6.0-beta.1. Exercise cancellation, multiple adapters and a routed camera. Confirm the existing Live View still plays independently.
2. Try security and protocol reads with valid credentials, insufficient permissions, HTTP and explicitly trusted HTTPS. Check custom ports and RTSP description failures.
3. Search known NVR recording periods and compare returned tracks/intervals/gaps, disk information and clock with recorder playback. This version does not claim verified replay.
4. On an explicitly authorised test camera, read imaging capabilities, confirm one reversible setting, check readback/video, then confirm restoration. Check behaviour on camera timeout before further writes.
5. Feed a supported ANPR camera test plates; verify local event text/confidence/time against actual camera events. Grade approved test cases and confirm plate retention expires. NVR/VMS receipt is not inferred.
6. Print and scan a label, change a saved IP and resolve the original QR again. Review/redact a bundle; verify optional screenshots and encrypted ZIP round-trip.
7. Use replacement as a dry-run plan first. Firmware transfer/reboot, automatic replacement provisioning/cloning/NVR reassociation, privacy-mask editing, vendor-only ANPR feeds and synthetic VMS injection remain gated/unsupported as documented.

There are no new privileged system dependencies for ordinary use. Optional dumpcap/Npcap tracing requires a separate existing, authorised installation; the app never installs or elevates it.
