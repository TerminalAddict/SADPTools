# SADPTools v0.3.0-beta.2 — Linux installers

Linux users can now install SADPTools with a DEB, Fedora RPM or a manual Bash
installer. Each includes the desktop application, CLI, application-menu entry,
SADPTools icon and licence notices. Upgrades and removal preserve saved sites,
encrypted credentials and preferences.

## Downloads

- **[Ubuntu/Debian DEB](https://github.com/TerminalAddict/SADPTools/releases/download/v0.3.0-beta.2/SADPTools-0.3.0-beta.2-linux-amd64.deb)** — install using `sudo apt install ./SADPTools-0.3.0-beta.2-linux-amd64.deb`.
- **[Fedora RPM](https://github.com/TerminalAddict/SADPTools/releases/download/v0.3.0-beta.2/SADPTools-0.3.0-beta.2-linux-x86_64.rpm)** — install using `sudo dnf install ./SADPTools-0.3.0-beta.2-linux-x86_64.rpm`.
- **[Linux manual installer](https://github.com/TerminalAddict/SADPTools/releases/download/v0.3.0-beta.2/SADPTools-0.3.0-beta.2-manual-linux-amd64.tar.gz)** — extract, then run `./install.sh` for the current user or `sudo ./install.sh --system` for all users. Includes uninstall support and checks for missing libraries.
- **[Windows setup](https://github.com/TerminalAddict/SADPTools/releases/download/v0.3.0-beta.2/SADPTools-0.3.0-beta.2-Setup-windows-amd64.exe)** — includes the offline WebView2 runtime.
- **[Standalone Windows desktop ZIP](https://github.com/TerminalAddict/SADPTools/releases/download/v0.3.0-beta.2/SADPTools-0.3.0-beta.2-standalone-windows-amd64.zip)** — extract and run `SADPTools-windows-amd64.exe`; WebView2 must already be present.

The lowercase `sadptools-...` archives contain only the standalone CLI. All
downloads are AMD64/x86_64. `SHA256SUMS` and `build-manifest.json` identify the
release files and source commit.

Linux packages use distribution-managed GTK4 >= 4.14 and WebKitGTK 6.0, targeting
Ubuntu 24.04+, Debian 13+ and current Fedora. APT/DNF resolve missing dependencies;
the manual installer reports them without installing system packages itself.
See the [Linux installation guide](https://github.com/TerminalAddict/SADPTools/blob/v0.3.0-beta.2/docs/linux-packaging.md).

## Updating

Windows users can enable beta updates and use **About → Check for updates →
Update now**. Setup installs the registered application; it does not overwrite
an arbitrary standalone EXE. Launch the installed app from the Start menu and
confirm About shows `0.3.0-beta.2`, or download/extract the new standalone ZIP.

Linux users should install subsequent packages with the same package manager,
or rerun the new manual installer using the original installation scope/prefix.
Automatic Linux update installation is not included.

## Validation and limitations

- Go tests, vet and race checks; frontend tests/build; installer and release-tool
  tests; Windows cross-build and Linux package builds are part of release validation.
- Linux package metadata, checksums, licence contents, script linting and desktop
  entry validation have been checked. Manual install/upgrade/removal tests pass.
- The packaged Linux GUI opened under Xvfb using an isolated installation and
  settings directory. This does not establish GNOME/KDE/Wayland compatibility.
- Real GNOME/KDE menu behaviour, Fedora installation/runtime and Windows
  installation/update handoff still need hands-on testing. No camera writes were
  performed for this packaging release.
- Windows signing remains pending; SmartScreen may still show Unknown publisher.
  Linux packages are also unsigned. This release adds packaging and retains the
  existing technician toolkit and firmware-compatibility limitations.
