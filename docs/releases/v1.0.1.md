# SADPTools v1.0.1 — NX Witness site information

Full NX Camera Info JSON imports now retain NX Witness **system, server, user,
storage and licence information** alongside camera inventory and known passwords.

- A site-specific **NX Witness** button opens read-only System, Servers, Users,
  Storage and Licences sections with search, column sorting and pagination.
- The button is absent from sites created through discovery/manual entry and from
  older camera-only imports. Empty NX sections do not add an empty area.
- Licence keys/blocks use explicit disclosure controls. Unknown, zero and false
  values remain distinct; permission bitmasks retain their exact integer values.
- NX information is encrypted locally and included in whole-site `.sadpsite`
  exports. Transfers preserve server/storage references and re-encrypt the
  snapshot for the destination laptop. Ordinary reports/previews exclude the
  private contents; previews show section counts only.
- The view is labelled as an imported snapshot, and closes when the vault locks.
  It does not contact or modify NX servers, users, licences or cameras.

**To use this with an existing site, import a fresh full NX Camera Info JSON
export into a new site.** Earlier imports discarded these fields. Existing sites
are preserved. Use v1.0.1 or newer when transferring sites with NX snapshots.

The supplied export was validated with **31 cameras, 2 servers, 5 users,
6 storage locations and 10 licences**, including encrypted export/import into a
separate vault. Temporary test stores were removed and no devices were contacted.
Synthetic tests cover storage/privacy, validation, compatibility and UI behavior;
light/dark desktop/mobile browser checks include accessibility validation.

Release checks include Go tests/vet/race, desktop service tests, frontend and
packaging tests, native CI across Windows/Linux/Apple Silicon/Intel, universal
Mac bundle validation, and SHA-256 verification of every uploaded release asset.
Native desktop interaction with real saved sites still needs field testing.

Downloads include the Windows offline installer and standalone desktop ZIP,
Linux DEB/RPM/manual packages, universal Mac DMG/ZIP, Windows/Linux CLI archives,
checksums and build provenance. Windows remains unsigned; Mac bundles use ad-hoc
signatures without notarization. Existing platform requirements and camera
compatibility limits are unchanged from v1.0.0.

See [NX Witness site information](https://github.com/TerminalAddict/SADPTools/blob/v1.0.1/docs/nx-witness.md)
and [site transfers](https://github.com/TerminalAddict/SADPTools/blob/v1.0.1/docs/site-transfer.md).
