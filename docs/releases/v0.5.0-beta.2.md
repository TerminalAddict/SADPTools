# SADPTools v0.5.0-beta.2 — Add cameras by IP

This beta adds **Add camera by IP** to Sites and the IP scanner. Connect to
one known IPv4 camera across an existing route or VPN, inspect HTTP/HTTPS/RTSP
services and read identity through ONVIF or Hikvision-compatible ISAPI. Review and
save the camera to a site, with optional Live View afterwards.

- No multicast discovery or adapter selector for this direct connection.
- Custom ports and ONVIF URL; saved or one-time read-only credentials.
- Progress, cancellation and explicit HTTPS certificate approval.
- Unknown fields remain unknown; unverified addresses require explicit consent.
- Duplicate identities preserve existing records. IP collisions require review.
- No camera configuration writes or automatic credential retries across services
  after an authentication rejection. One-time passwords are never persisted.

See [the usage and validation guide](https://github.com/TerminalAddict/SADPTools/blob/v0.5.0-beta.2/docs/add-camera-by-ip.md). Go test/vet/race,
33 frontend tests, 34 packaging tests, desktop-tagged checks, Windows/Linux builds
and a native Linux synthetic-service smoke test passed. Windows execution and
real routed camera/Live View testing remain to be done.

- **[Fedora RPM](https://github.com/TerminalAddict/SADPTools/releases/download/v0.5.0-beta.2/SADPTools-0.5.0-beta.2-linux-x86_64.rpm)**
- **[Linux manual installer](https://github.com/TerminalAddict/SADPTools/releases/download/v0.5.0-beta.2/SADPTools-0.5.0-beta.2-manual-linux-amd64.tar.gz)** — extract and run `./install.sh`.

All builds target AMD64/x86_64. The lowercase `sadptools` archives contain the
headless CLI. `SHA256SUMS` and `build-manifest.json` identify the downloads and
their source commit. Linux GUI packages require GTK4/WebKitGTK system libraries;
see the [Linux installation guide](https://github.com/TerminalAddict/SADPTools/blob/v0.5.0-beta.2/docs/linux-packaging.md).

Close the running standalone app before replacing its EXE. Confirm **About**
shows `0.5.0-beta.2`. With beta updates enabled, the in-app updater offers this
release's Setup installer; it installs the Start menu app rather than replacing
an arbitrary standalone file. Existing sites and settings remain in the user's
configuration directory. This release requires no database schema migration.

Windows builds remain unsigned. Windows execution and physical routed-camera
testing have not been performed. This feature does not extend local SADP
activation or network-configuration commands across routers.
