# SADPTools v0.2.0-beta.1

The first public beta of SADPTools, an open-source desktop utility and CLI for
discovering and managing Hikvision devices. Created by [Paul Willard](https://www.paulwillard.nz/)
(TerminalAddict), built with Go and Wails v3, and released under the MIT licence.

## Download and install

**Windows 10/11, Intel/AMD 64-bit:** download
**[SADPTools-0.2.0-beta.1-Setup-windows-amd64.exe](https://github.com/TerminalAddict/SADPTools/releases/download/v0.2.0-beta.1/SADPTools-0.2.0-beta.1-Setup-windows-amd64.exe)**,
run it, then open SADPTools from the Start menu. The installer includes everything
needed for the interface and can install offline; there are no separate runtime
downloads. Close an existing SADPTools instance before installing.

For terminal users, download the Windows CLI ZIP or Linux CLI tar.gz, extract
it, and run `sadptools --version`, `sadptools interfaces` or `sadptools discover`.
The CLI needs no graphical desktop or display runtime. SHA-256 checksums and a
build manifest accompany the downloads. GitHub's source archives are for developers.

## Included

- Real SADP discovery on selected or all suitable IPv4 adapters, with deduplicated
  inventory, cancellation, timeouts and periodic scans.
- Device model, addresses, MAC, serial, firmware and activation status when
  advertised by the camera. Unknown values stay unknown.
- Searchable, sortable desktop table, device details, CSV/JSON export, diagnostics,
  web-interface action, saved settings and dark/light themes.
- Single-device activation, IPv4/DHCP/SDK-port settings and support-code password
  recovery workflows. Desktop actions automatically use an adapter that discovered
  the selected device; multiple connections have an optional override.
- Standalone Windows and Linux CLIs using the same native Go networking engine.
- Signal Lens branding, an About screen and a complete offline Windows installer.

## Beta limitations and validation

- Basic discovery has been exercised with real Hikvision devices on Linux,
  including detection of an inactive camera. Automated Go tests, vet/race checks,
  frontend tests and packaging/release integrity checks cover synthetic cases.
- Windows cross-compilation and installer packaging are checked on Linux.
  Windows installation, startup, firewall behaviour and multiple-adapter operation
  still need testing on Windows. The Linux GUI has been inspected under Xvfb;
  a generic Linux desktop binary is not included because GTK/WebKit runtime
  requirements vary by distribution.
- Activation, network changes and password recovery are implemented but have
  **not been validated with physical-device write operations**. Firmware support
  varies. Recovery uses a valid vendor/support-provided code; it does not bypass
  passwords or provide an exploit. Vendor XML/GUID/email recovery and encrypted
  command variants are not implemented.
- A command timeout can occur after a device has changed. Verify its state before
  retrying. Discovery needs a suitable local Layer 2 network; VLANs, isolation and
  firewalls can prevent responses. Allow UDP 37020 on the intended trusted network.
- The app and installer are unsigned, so Windows may display an unknown-publisher
  or SmartScreen warning. The bundled Microsoft runtime is unmodified; its
  Authenticode signature and clean offline installation remain Windows checks.
- No firmware upgrades, batch configuration, ONVIF or non-Hikvision support yet.

Please report reproducible problems through [GitHub Issues](https://github.com/TerminalAddict/SADPTools/issues),
including the SADPTools version, OS, camera model/firmware and what happened.
Remove passwords, recovery data and private device identifiers from reports.
See the [device-management guide](https://github.com/TerminalAddict/SADPTools/blob/v0.2.0-beta.1/docs/device-management.md)
for supported operations and their limits.

SADPTools adds no cloud account or telemetry. Microsoft's bundled display
runtime has its own update and privacy terms, included in setup. Protocol work
includes MIT-licensed adaptations from Cameron Newman's
[hikvision-tooling](https://github.com/cameronnewman/hikvision-tooling); full notices
ship with the downloads.
