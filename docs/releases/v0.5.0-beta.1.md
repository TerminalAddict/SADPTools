# SADPTools v0.5.0-beta.1 — Commissioning tools

This beta adds the ten v0.5 roadmap workflows to the existing saved sites,
credentials and separate Live View window:

- Read-only Hikvision NVR channel inventory, stable camera links and advertised
  channel streams.
- Stream diagnostics, timed connection tests and main/sub comparisons.
- Focus/alignment overlays, digital zoom, sharpness trend and snapshot evidence.
- Capability-checked ONVIF PTZ, motor focus, presets and a bounded tour preview.
- Timed ONVIF event walk-tests with per-event grades and saved evidence.
- Encrypted settings capture, structured comparison and restore/clone preview.
- Storage/retention scenarios with bitrate provenance, schedules and ranges.
- Offline site plans with device markers, layers, history and coverage guides.
- Commissioning checklists, reusable branding and offline PDF/HTML handovers.
- Explicit remote site discovery over SSH with strict host-key verification.

Configuration restore remains disabled until approved physical-device validation,
as required by the roadmap. Settings capture is partial; unsupported sections and
unknown measurements are labelled. PTZ and focus require supported capabilities,
a verified device identity and explicit operator action. No real camera writes
or movement were performed during development.

## Downloads and updating

- **[Windows offline Setup](https://github.com/TerminalAddict/SADPTools/releases/download/v0.5.0-beta.1/SADPTools-0.5.0-beta.1-Setup-windows-amd64.exe)** — includes the display runtime and Start menu shortcut.
- **[Standalone Windows desktop ZIP](https://github.com/TerminalAddict/SADPTools/releases/download/v0.5.0-beta.1/SADPTools-0.5.0-beta.1-standalone-windows-amd64.zip)** — extract and run `SADPTools-windows-amd64.exe`.
- **[Debian/Ubuntu DEB](https://github.com/TerminalAddict/SADPTools/releases/download/v0.5.0-beta.1/SADPTools-0.5.0-beta.1-linux-amd64.deb)**
- **[Fedora RPM](https://github.com/TerminalAddict/SADPTools/releases/download/v0.5.0-beta.1/SADPTools-0.5.0-beta.1-linux-x86_64.rpm)**
- **[Linux manual installer](https://github.com/TerminalAddict/SADPTools/releases/download/v0.5.0-beta.1/SADPTools-0.5.0-beta.1-manual-linux-amd64.tar.gz)** — extract and run `./install.sh`.

All builds target AMD64/x86_64. The lowercase `sadptools` archives contain the
headless CLI, including the versioned SSH discovery protocol. `SHA256SUMS` and
`build-manifest.json` identify the downloads and their source commit. Linux GUI
packages require GTK4/WebKitGTK system libraries; see the
[Linux installation guide](https://github.com/TerminalAddict/SADPTools/blob/v0.5.0-beta.1/docs/linux-packaging.md).

Close a standalone Windows app before replacing its EXE. Confirm **About** shows
`0.5.0-beta.1`. The in-app updater offers this release when beta updates are
enabled; it installs Setup and the Start menu application rather than replacing
an arbitrary standalone file. Existing data stays in the user's configuration
directory. Schema 3 creates a migration backup, and portable encrypted site
backups now include the new evidence. Retain a site backup before testing.

## Validation and limitations

Go test/vet/race, 31 frontend tests, 34 packaging tests, native Linux synthetic
video/evidence/PDF checks, and Windows/Linux builds passed. Windows runtime,
physical cameras/NVRs, PTZ movement and a real remote site remain operator checks.
Windows signing remains pending. See [the technician guide](https://github.com/TerminalAddict/SADPTools/blob/v0.5.0-beta.1/docs/ADVANCED_FEATURES.md)
and [validation checklist](https://github.com/TerminalAddict/SADPTools/blob/v0.5.0-beta.1/docs/ADVANCED_FEATURES_VALIDATION.md) for compatibility
limits and exact test coverage.
