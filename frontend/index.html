Connection options

This device was discovered through multiple adapters. SADPTools chooses one automatically; you can override it here if needed.

All fields are sent. With DHCP enabled, these are the stored static settings. The SDK port is separate from the web interface port. An address change can disconnect existing clients.

Obtain a valid reset code through your authorised support provider. Support varies by firmware. Vendor XML imports, GUID files, security questions and email recovery are not supported here.

Passwords and codes are not saved in preferences or logs. This SADP command format sends them over the local network without encryption; use a trusted management network.
